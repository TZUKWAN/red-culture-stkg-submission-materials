# 长江流域红色文化时空知识图谱 V2 研究与构建报告

更新时间：2026-07-15  
研究目标：解释长江流域红色文化如何随历史阶段、地域、主体、事件、载体和文化形态发生演进。红色文化是研究对象，红色精神是可选线索，不是所有节点的强制中心。

## 1. 结论

V2 已形成一个事件组织、事实可追溯、时间与空间角色分离、红色文化形态模块化的时空属性图。它不是把 424,150 条记录逐条人工重写，而是在不可变来源层之上，通过模式约束、实体消歧、程序化标签、少量模型裁决、风险分层和全量约束重建派生层。

此前工作没有被推翻。被保留并继续使用的核心资产包括：424,150 条整合断言、466,312 条来源关联、稳定 ID、原始主客体和关系、原始时空文本、实体别名与成员谱系、13 省区市词表、历史阶段词表、专题作品/物品/精神材料以及原子发布基础设施。V2 重建的是会受语义规则影响的派生结果：最终实体类型、时空角色、事件框架、文化状态、演进候选和 Neo4j 投影。

最终全量审计为 PASS，失败项为 0。最终数据库 SHA-256 为 `a199d736b9ec436b3d5f244e874718604b6c84955a505f31f90a3e28c51a9ee7`；受保护 V1 的 SHA-256 仍为 `416578c5d3ae7d14193982d9d35f26c8b6e8665cd9b6399d47b67361ab1c48bd`。

## 2. 文献依据与构建范式

本项目采用的不是“逐条人工建图”，而是成熟知识图谱项目共同使用的分层和增量范式：

1. [EventKG](https://arxiv.org/abs/1905.08794) 从多个大型知识图谱和半结构化来源整合事件与时序关系，使用统一事件表示、实体融合和来源保留，而不是逐条重写来源。
2. [OEKG](https://arxiv.org/abs/2302.14688) 通过统一模式和稳健流水线整合多个事件数据集，说明事件图谱需要公共 Schema 和可复用管线。
3. [KnowWhereGraph Ontology](https://arxiv.org/abs/2410.13948) 使用模块化本体整合 30 多个空间数据层，说明时空图谱应将空间、事件、观察和元数据分模块治理。
4. [ArCo 的模式化设计](https://arxiv.org/abs/1911.07585) 以能力问题、Ontology Design Pattern 和测试驱动方法构建文化遗产图谱，支持本项目“先冻结研究问题，再验证 Schema”的路线。
5. [DeepDive](https://arxiv.org/abs/1502.00731) 将候选生成、数据库规则、特征和统计推断分开，并支持增量重算，说明规则变化时应重算派生层而不是重做来源层。
6. [Snorkel](https://arxiv.org/abs/1711.10160) 用标签函数表达规则、词典和外部知识，再融合弱标签，支持“程序化监督 + 冲突分流”。
7. [Knowledge Vault](https://research.google/pubs/knowledge-vault-a-web-scale-approach-to-probabilistic-knowledge-fusion/) 融合文本、表格、页面结构、人工标注和既有知识库，并对事实计算概率，说明多来源抽取结果不能直接等同于单一确定事实。
8. [时空知识图谱模型综述](https://arxiv.org/abs/2512.16487) 指出不同应用采用不同的时空标注语义，且来源谱系应与时空信息共同保留；本项目因此采用面向历史文化研究的领域模型，而不是照搬交通预测图。
9. [LLM 与知识图谱综述](https://arxiv.org/abs/2308.06374) 强调实体消歧、长尾实体、精确率和来源谱系风险，因此千问仅用于规则无法裁决的小部分候选，不直接生成无来源历史事实。

这些文献形成的稳定方法是：保留来源和原始声明，批量生成候选语义，融合规则/模型判断，使用本体和约束校验，只把冲突或长尾交给模型/人工，最后通过能力问题、全量约束和分层抽样评价。

## 3. 数据分层

| 层级 | 作用 | 是否可重算 |
|---|---|---|
| L0 SourceRecord | 来源记录、来源主键、原文位置和来源元数据 | 不覆盖 |
| L1 Raw/Integrated Assertion | 424,150 条整合声明及原始主客体、关系、时空文本 | 不删除 |
| L2 CanonicalEntity | 规范实体、别名、成员、最终类型和验证状态 | 版本化重算 |
| L3 ScopedAssertion | 关系语义、时间角色/归属、空间角色/归属、研究层级 | 版本化重算 |
| L4 EventFrame | 事件时间、地点、角色、事件关系和可信度 | 从 L3 重建 |
| L5 CultureState | 文化主体在阶段、区域、流域区段和文化形态中的观察状态 | 从 L3/L4 重建 |
| L6 Evolution | 描述性变化、候选转化和显式结构转化 | 从 L5 重建 |
| L7 Graph/UI | Neo4j 全图、中文检索界面和能力查询 | 从最终库重建 |

“派生层可重算”不等于“此前数据作废”。它等同于数据库中的物化视图或机器学习中的特征层：基础数据不变，规则改进后重新计算受影响的结果。

## 5. 时空与字段统一

### 5.1 时间

时间值与时间语义分开存储。`time_start/time_end` 保存可计算区间，`normalized_time_label` 保存统一中文显示，`time_precision` 保存原有精度，`time_role/time_owner_id` 说明时间属于谁、表示什么。

统一显示范式是“保精度规范族”，而不是凭空补月：

- 年：`1941年`；
- 月：`1943年8月`；
- 年区间：`1934年-1936年`；
- 月区间：`1934年10月-1936年10月`；
- 未知：结构化字段为空，精度为 `unknown`。

最终库不出现“一九四一年”、`1943-02` 或 `1943年2月15日` 等混合显示；也不会把只知道年份的数据伪造为某个月。时间精度分布为 unknown 346,220、period 41,118、year 23,947、month 12,865。

时间角色分布为：unknown 346,220、context_time 51,437、relation_validity 20,821、biographical 4,668、event_occurrence 910、creation_or_publication 42、source_document_time 35、commemoration_or_reception 17。只有 `event_occurrence + 正确 Event owner` 才能进入事件发生时间。

### 5.2 空间

空间同样区分原始文本、规范锚点、行政区字段、流域区段、空间角色和空间归属。空间角色分布为 unknown 318,515、context_location 75,153、relation_location 22,422、event_location 7,673、biographical_location 373、纪念/接受地点 12、创作/出版地点 2。

一个地点与某事件同时出现，不自动成为事件发生地；只有 `event_location + 正确 Event owner` 才进入事件地点。13 省区市和上中下游为研究范围词表，不代表每个切片都有观察数据。

### 5.3 最终类型闭包

实体身份融合后，V2 对全部 424,150 条断言重新检查时空角色与最终实体类型的一致性，保留所有仍合法的既有审定，只修结构上失效的记录。最终产生 208 条可追溯调整：60 条已知时间从 unknown 闭合为事件时间；44 条错误时间归属降级；120 条错误或失效空间归属降级，其中部分时间与空间调整发生在同一断言。没有把既有 context 记录提升为强事件角色。

## 6. 红色文化演进的可观察结果

### 6.1 历史阶段

文化状态按阶段分布为：建党前传播与孕育 356、建党与大革命 1,661、土地革命战争 3,416、全民族抗日战争 2,451、解放战争 2,286、社会主义革命和建设 1,279、改革开放和社会主义现代化建设 83、新时代 0。

在当前数据中，状态数量在土地革命战争阶段达到最高，随后在抗日战争和解放战争阶段保持较高规模；社会主义革命和建设阶段仍有大量制度实践与记忆转化。这个结果表示“数据集中的可观察结构”，不能直接等同于历史时期的真实文化强度，因为来源覆盖、抽取密度和时空字段缺失会影响数量。

### 6.2 区域与流域区段

状态较多的省域为湖南 1,363、湖北 1,331、江西 1,298、四川 1,286、贵州 1,243、云南 1,226、江苏 1,218。青海为 0、西藏为 2、浙江为 77。这个差异只能说明当前结构化材料的观察覆盖，不应写成相关省域“没有”或“较少拥有”红色文化。

上游、中游、下游分别有 4,368、3,992、3,172 个文化状态；可信状态分别为 313、421、224。中游可信状态相对集中，上游全量状态更多，说明不同口径下分布不同，论文必须同时报告全量、候选和可信口径。

### 6.3 七类红色文化形态

| 文化形态 | 全部状态 | 可信状态 |
|---|---:|---:|
| 历史实践 | 7,066 | 201 |

这表明当前底层材料和关系抽取明显偏向历史事件、组织与制度实践。文艺作品和物质文化虽已进入实体层，但因大量记录缺少可归属的时间/空间，进入 CultureState 的数量较少。论文不能把状态占比直接解释为红色文化本体的真实构成比例。

### 6.4 事件骨架

V2 有 28,065 个 Event 实体，形成 140,830 条事件关联和 54,033 条受控事件角色。696 个事件具有可观察发生时间，其中 95 个达到可信时间门槛。皖南事变、南昌起义、四渡赤水、渡江战役、秋收起义、红军长征、武汉会战和遵义会议等形成高连接事件骨架。

“连接多”只表示在本数据集中关联丰富，不表示历史重要性排名。部分著名事件仍可能没有可信发生时间，例如当前南昌起义事件框架的时间状态为 `none`；V2 选择保留未知，而不是用人物生平、文献出版或相邻记录的时间补写事件时间。

### 6.5 文艺作品

1,019 个 CreativeWork 均具有媒介字段。主要媒介为歌曲 275、小说 165、话剧 156、电影 74、诗歌 69、戏剧 55、剧本 46、歌剧 28、舞蹈 24、纪录片 14、电视剧 8；另有报告文学、舞剧、雕塑、曲艺、漫画、理论著作、文集、连环画、动画片、绘画、广播剧、散文等。57 个作品保留为“未知”，没有为填满字段而猜测。

### 6.6 红色精神与价值内涵

Spirit 是红色文化分析的一个维度，不是强制中心。最终库保留 1,331 个 Spirit、691 个 ValueFacet 和 1,386 条显式精神-价值关系；在 CultureState 上形成 532 条价值内涵投影，涉及 133 个状态和 4 个显式进入状态层的 ValueFacet。该层可回答共同价值内涵跨阶段、跨地区如何被观察，但不能仅凭共同内涵推断不同精神之间存在继承或因果关系。

### 6.7 显式演进关系

159 个演进候选中只有 4 个通过发布门禁，类型均为 `memorialized_as`：

1. 红军长征 → 扎西红军纪念馆（云南）；
2. 红军长征 → 嵩明红军长征纪念碑（云南）；
3. 秋收起义 → 铜鼓纪念馆（江西）；
4. 苏南反顽战役 → 苏南反顽战役阵亡将士纪念塔（江苏）。

这说明现有显式关系最能支持“历史实践被纪念化/物质化”，尚不足以大规模发布传播、继承、制度化或因果演进边。论文研究演进不能只依赖这 4 条边，而应采用三个层次：阶段/区域/形态的描述演进、事件与主体网络的结构演进、少量显式支持的机制演进。

## 9. 研究边界

1. 本轮不做逐条外部史实核验；它保证结构一致、语义分层、同类合并和可追溯，不把每条断言声明为已由外部史料独立复核。
2. `first_observed` 表示数据集内首次观察，不表示历史起源。
3. 时间先后、共现、共同价值内涵和网络邻接不自动构成传播、继承或因果。
4. unknown 是合法值，缺月不补月、缺地点不猜地点、缺媒介不强行分类。
5. 地区和阶段计数受材料覆盖影响，不能直接解释为历史文化强弱。
6. V2 的派生层仍可在新增材料或更优规则下版本化重算，但 L0/L1、稳定 ID、来源链和发布版本不会被静默覆盖。

## 10. 论文建议

论文主线应写成：“长江流域红色文化在不同历史阶段和空间区段中，由革命历史实践逐步形成多主体、多载体和多形态结构，并通过制度组织、文献文艺、物质纪念和精神价值持续转化与传播。”

实证部分按四组结果组织：

1. 阶段结构：七类文化形态在各阶段的状态与可信口径变化；
2. 空间结构：13 省区市和上中下游的分布差异及覆盖边界；
3. 事件网络：关键事件连接人物、组织、地点、物品、文献和作品的结构变化；
4. 转化机制：只对显式支持的纪念化关系作机制解释，其余演进保持描述性或候选状态。

这一路线可以直接回答“长江流域红色文化如何演进”，同时避免把红色精神等同于红色文化、把数据数量等同于历史强度、把时序先后等同于因果。
