# 01 论文可视化需求拆解

生成时间：2026-09-18　依据：完整阅读稿件全文（21,851 字 + 6 表 + 8 图）与 v3_1 全部终版审计报告。

## 1. 研究问题与对象

- **研究问题**：大规模叙事史料知识图谱化中，候选知识的语义判定（是否可信）、结构发布资格（能否入严格层）、来源可追溯（能否返回原文）三环节相互脱节；如何组织为**同一条连续控制链**。
- **对象**：长江流域 13 省级行政区（沪苏浙皖赣鄂湘渝川黔滇藏青）983 册中共党史文献，302,230 页文本。
- **核心机制**（论文 §3 + AUTHORITATIVE_RESULTS 定版叙事）：
  1. 一级控制（选择性预测）：规则/本地分类器/LLM 多通道证据 + 可靠性门禁 + 独立信号 + 显式弃权 → 自动接受 / 升级裁决 / 弃权；
  2. 二级控制（结构准入/级联准入）：实体规范投影 → 关系契约（88 谓词 domain-range）→ 时空角色-归属对象约束 → 来源校验；
  3. 证据语义门（Evidence Gate）：对 112,158 严格候选逐条证据定位 + 五档语义支持判定（qwen3.5-4b，127,633 判定档案）；
  4. 分层发布：STRICT 31,067 / CONTEXTUAL 299,329 / UNRESOLVED 93,754（全库 424,150，replay 六零检查通过）。

## 3. 数据对象语义与知识状态形成路径

- **知识状态路径**：候选抽取（282,165 候选）→ 语义判定（接受/未决）→ 实体规范投影（794 决议）→ 关系契约 → 时空作用域（208 调整）→ 来源校验 → pre-gate 三层（strict 候选 112,158 / contextual 268,047 / unresolved 43,945）→ 证据语义门（STRICT 31,067 / CONTEXTUAL 31,282 / UNRESOLVED 49,809）→ 全库最终三层（31,067 / 299,329 / 93,754）。
- **三概念分离**：A 谱系完整率（provenance 指针）44.72%；B 证据定位率（文本可取回）98.12%；C 语义支持率（取回证据真支持）28.23%。A≠B（61,997 无原生指针中 59,891 靠词法恢复）；B≠C（recovery_C 定位成功但支持率仅 ~14.8%）。
- **六层定位桶**：aligned 44,025 / mismatch_with_evidence 6,136 / recovery_A 2,841 / recovery_B 16,705 / recovery_C 40,345 / recovery_D 2,106。

## 8. 图形纪律（从清单 §18–§25 提炼）

- 图型多样：≥35 种图型覆盖；柱状图不得占多数、饼图弃用。
- 每图回答一个新问题；同一重要逻辑（级联准入）允许 2–3 种完全不同视觉编码（Sankey/漏斗/瀑布/分层流），禁止换色换皮。
- 中文宋体、英文 Times New Roman、莫兰迪低饱和配色、轻轴线轻网格、无重叠、无裁切。
- 全中文图名与文件名；STRICT/CONTEXTUAL/UNRESOLVED 首次出现附中文解释。
- 每图 PNG(300–600dpi)+SVG+PDF 三格式；每图有脚本、有数据源、有元数据记录。
