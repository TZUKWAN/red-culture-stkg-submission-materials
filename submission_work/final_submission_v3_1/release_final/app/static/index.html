使用说明

  1. 顶部搜索实体，回车或点击结果载入其一跳子图。
  2. 左栏控制发布层（STRICT/CONTEXTUAL/UNRESOLVED）、实体类型、关系与时间范围。
  3. 单击节点展开其邻居；「最短路模式」下依次点两个节点求严格层最短路径。
  4. 点击连线打开证据抽屉：断言 → 判定 → 引文 → 溯源指针，一键复制 evidence id。
  5. 时间轴按年份过滤；导出 PNG/CSV 供论文与核查使用。

三层语义：STRICT=机器形成的规范化映射足够确定并通过证据语义门；CONTEXTUAL=原文信息在但映射/作用域不足以进入发布层；UNRESOLVED=当前无法形成可靠唯一映射或证据不足/冲突。三层不是史料可信度评级。
