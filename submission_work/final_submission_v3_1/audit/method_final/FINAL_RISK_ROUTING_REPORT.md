### 3.3 路由机制读数

- 翻转方向（错→对 : 对→错，R6 pooled）：b=5% 10:0、b=10% 20:0、b=20% 40:0、b=30% 53:1、b=40% 70:1、b=50% 85:1——各预算点升级都净换出质量，与旧报告升级段 99:2 同向；逐路由逐预算数字见 ROUTING_COMPARISON.csv 的 wrong_to_right / right_to_wrong 列。
- 每 10% 预算的一致率增益（pp/10% 预算，相对 b=0）：R6 在各预算点为 7.66、7.66、7.66、6.64、6.61、6.44。

**路由有效性最终判语：略优。** 判定规则：R6 vs R1/R2/R3 共 18 个（预算×对手）paired-bootstrap 比较——5 个显著为正（CI 全>0）、13 个不显著（CI 跨 0）、0 个显著为负（CI 全<0）；点估计为正 14/18。规则：全部显著为正⇒“显著优”；无显著为负且多数点估计为正⇒“略优”；其余⇒“无优”。逐项判定见 ROUTING_BOOTSTRAP.json / 上表。具体结构：R6 相对 R2（最低置信）/R3（最低 margin）的显著优势集中在中段预算（20%/40% 全部显著，30% 处 R2 显著、R3 处于边界）；相对 R1（随机）在任何预算都不显著（点估计 20–50% 为正、5–10% 约为 0，5% 处点估计还略低于 R1）——即在当前样本量下，risk 路由稳定优于单信号启发式，但不能宣称显著优于随机选择；统计意义上 R6 在任何预算都不显著劣于任何替代路由（0/18 CI 全负）。

## 4. 边界与诚实声明

1. 参考仍是 LLM-judge 共识（leave-B-out 去除与 gpt-5.6-luna 同族的 Judge B），所有一致率读作“对去 B 共识的一致率”，不等于人工金标正确率。
2. 样本量小（pooled 有参考 261 条，每预算升级 13–160 条），CI 宽；判定以 CI 是否跨 0 为准，不炒作点估计。
3. 升级模型只有本地 gpt-oss-20b 单模型、温度 0；更强模型会右移整条曲线。
4. 无弃权口径：本对比全部样本发布（升级换决策、其余发基础预测），与旧报告的 accept/abstain 选择性口径不同，数字不可直接互比。
5. R1 的随机性由 seed=20260910 单次实现给出，未平均多次随机抽取（bootstrap CI 已覆盖抽样变异；多 seed 重复未做，属剩余不确定性）。
6. every-item 调用 319/320 成功；ETV3-0041在温度 0 下确定性 JSON 解析失败，按政策回退基础预测（与旧 risk_routing 运行的 ERROR 记录一致，每次重跑自动重试）。
