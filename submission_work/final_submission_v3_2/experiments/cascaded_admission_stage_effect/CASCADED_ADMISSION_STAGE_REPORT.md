## 三、结论（数据支持的边界内）

1. 若把 112,158 条前置严格候选直接发布，独立双裁判强共识证据支持率总体仅约 22%；
2. 经证据语义核验后的 Final STRICT 层，该口径支持率为 42.55%——
   **严格知识层的独立证据支持质量因 Evidence Gate 显著提升**；
3. 被降级候选的支持率（16.4%）显著低于被保留者（42.6%）——
   证据门的取舍方向与独立裁判一致；
4. 门外加权 STRICT 机会仅 0.66% [0.40, 0.97] ——前置准入造成的潜在遗漏处于低水平。

方向 1（提升严格层质量）与方向 2（少量遗漏）共同构成级联准入整体有效性的实证。
